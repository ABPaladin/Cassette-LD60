# Shared bundled interface font

Courier Prime Regular, unmodified, by the Courier Prime Project Authors.
Source: https://github.com/google/fonts/tree/main/ofl/courierprime
License: SIL Open Font License 1.1, included as OFL.txt.

This is a portable temporary typewriter font, not Vintage Typist. The latter was
not supplied. The shared resources/interface_font.tres wraps this FontFile so
both desktop and Web load identical glyphs without access to OS-installed fonts.
Assign a licensed final font to its base_font when supplied.
